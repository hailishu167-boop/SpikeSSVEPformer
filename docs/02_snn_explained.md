# 02 · SNN 讲解：LIF 神经元、脉冲编码与替代梯度

> 只需要高等数学 + 线性代数就能看懂。读完你将理解：SNN 和普通神经网络（ANN）的本质区别、LIF/PLIF 神经元的数学模型、以及最关键的——离散的脉冲怎么用梯度下降训练。

## 1. ANN 和 SNN 差在哪？

普通神经网络（ANN）的神经元输出一个**连续值**：

```
y = ReLU(w·x + b)
```

而生物神经元不是这样工作的。真实神经元通过**脉冲（spike）**通信：膜电位慢慢积累，超过阈值就「啪」地发放一个脉冲，然后复位。信息编码在**脉冲的时间/频率**里，而不是连续数值里。

SNN（脉冲神经网络）就是模拟这种机制的神经网络，被称为「第三代神经网络」。优势：生物合理性、事件驱动带来的低功耗潜力（在神经形态芯片上）；代价：训练困难（下面会讲为什么）。

## 2. LIF 神经元：一个 RC 电路

**LIF（Leaky Integrate-and-Fire，泄漏积分发放）** 是最常用的脉冲神经元模型。把神经元想象成一个漏电的电容：

```
膜电位 V(t) 的演化（离散时间步）：

    V[t] = V[t-1] + (1/τ)·(X[t] - (V[t-1] - V_reset))

    如果 V[t] ≥ V_th（阈值）：
        发放脉冲 S[t] = 1
        V[t] ← V_reset（复位，本项目设为 0）
    否则：
        S[t] = 0
```

三个参数：

- **τ（tau，膜时间常数）**：控制「漏电/积分速度」。τ 大 → 电位衰减快、神经元「健忘」；τ 小 → 积分久、更容易积累发放。电路类比：τ = R·C。
- **V_th（发放阈值）**：本项目取 1.0（融合层取 0.5）。
- **V_reset（复位电位）**：发放后电位回到哪。

直觉：输入 X 像往一个底部漏水的桶里注水，水满（超过阈值）就倒空一次（发放一个脉冲）。**输入越强，倒水的频率越高**——这就是「发放率编码」（rate coding）：用单位时间脉冲数表示数值大小。

## 3. PLIF：让 τ 变成可学习参数

**PLIF（Parametric LIF）** 是普通 LIF 的小改进，也是本项目主模型名字的来源：

> τ 不再手调，而是每个神经元一个可学习参数，用反向传播自动学出来。

为什么有意义？不同子带、不同通道的 EEG 特征，其最优时间动态可能不同——有的需要快速响应，有的需要长时积分。让网络自己学 τ，相当于让每个神经元自适应自己的「记忆长度」。本项目里 `models/plif_ssvepformer.py` 的 `PLIFEncoder` 和 `PLIFFeatureFusion` 用的都是 `ParametricLIFNode(init_tau=2.0)`。

## 4. 本项目怎么用 SNN？——发放率编码

看 `PLIFEncoder.forward` 的核心片段（有注释）：

```python
x_snn = x.permute(2, 0, 1)          # 把频率维当作「时间步」维
self.lif.reset()                     # 清空膜电位（每个 batch 必须做！）
spike_out = []
for t in range(T_snn):               # 跑 T 个时间步
    spike = self.lif(x_snn[t])       # 每步输入一个「时间片」
    spike_out.append(spike)
x_snn = torch.stack(spike_out).mean(dim=0)   # 对时间取平均 = 发放率
```

要点：

1. **输入当作时间序列**：把特征的一个维度（这里是频率维）依次喂给神经元，喂 T_snn 步（训练时 T_snn=12）。
2. **输出取脉冲平均值**：T 步里发了几次脉冲 ÷ T，就是发放率，一个 [0,1] 的连续值，可以继续往后传。
3. **`reset()` 必不可少**：膜电位是有状态的，不 reset 的话上一个样本的残留电位会污染下一个样本。这是 SNN 编程最常见的 bug 来源。

分类头里的 `MlpHeadLIF` 思路相同：两个 Linear 层之间插一个 LIF「脉冲瓶颈」，迫使决策信息经过一层稀疏的 0/1 脉冲表示，起到正则化和非线性增强的作用。

## 5. 最关键的问题：脉冲不可导，怎么训练？

脉冲发放是一个**阶跃函数**：

```
S = 1  (V ≥ V_th)   否则  S = 0
```

阶跃函数的梯度几乎处处为 0（阈值处为无穷大）——反向传播到这里梯度直接消失，没法训练。这是 SNN 的核心难题。

**解决方案：替代梯度（surrogate gradient）**——前向传播用真的阶跃函数，反向传播时偷偷把它的导数换成一个光滑的「替身」。本项目用 **ATan（反正切）替身**：

```
前向：S = Θ(V - V_th)          （真阶跃）
反向：∂S/∂V ≈ (α/2) / (1 + (π·α/2·(V - V_th))²)    （ATan 的光滑导数，一个钟形曲线）
```

直觉：虽然严格来说脉冲处不可导，但我们告诉优化器「膜电位离阈值越近，对脉冲的影响越大」——这在物理上是合理的近似。实验证明这样训练效果很好，spikingjelly 库一行代码搞定：

```python
from spikingjelly.activation_based import surrogate
neuron.ParametricLIFNode(surrogate_function=surrogate.ATan(), ...)
```

## 6. 为什么 SSVEP 适合 SNN？（设计动机）

SSVEP 是大脑对**周期性**刺激的响应，本质是一种振荡、一种节律放电；而 SNN 恰恰是建模「神经元群体节律放电」的天然工具。把频域特征序列喂进 LIF，相当于用一个带泄漏的积分器去「共振」这些频率成分——PLIF 学到的 τ 决定了积分窗口，和共振频率直接相关。

当然，要诚实地说：SNN 是不是**一定**比 ANN 强？本项目同文件里保留了纯 ANN 基线 `FBSSVEPformerV4PLIFBaseline`，就是让你自己做消融实验验证这一点的。科研的基本功：任何「我觉得有用」的模块，都要拿对照实验说话。
